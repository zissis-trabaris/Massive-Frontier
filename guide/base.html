The Command Bridge

The Command Bridge is the heart of your base. Its Mark is your Bridge level (1 to 5). The Bridge level decides which buildings you can build and how much of the base grid is open. The Bridge can't be demolished, but it can be moved onto any "Any" tile.

How the grid grows, what each tile type holds, and how to build, move and re-type tiles are all covered in the Base Layout guide.

Power

Every building except the Bridge, Reactors and Barricades draws power. The Bridge provides 20, and each Fusion Reactor provides 100 (more at higher Marks). You can only place a building if your power budget covers it, so build Reactors before you run out.

Turrets, shield generators, screen projectors, combat arrays and barricades count towards your base's Defense Rating, which is shown on your map marker. They start defending for real when base battles arrive. The Warp Gate needs a Bridge level higher than the current maximum, so it can't be built yet.

The build queue

Every build and every upgrade goes through the build queue. Only the first item counts down; the rest wait their turn. The queue keeps running while you are offline. The Bridge gives two queue slots, and your base level adds more:

Base levelQueue slots
Base level 1+2
Base level 3+3
Base level 5+4
Base level 7+5
Base level 9+6

Each queued item has Speed Up and Cancel buttons (Coins and refunds).

Upgrading buildings

Every building has five Marks. Upgrading raises its health, its output (production, storage, reactor power, shield energy) and its power draw. A building that is upgrading can't be fitted or moved.

Base level

Your base level comes from what is standing in your base: each building's XP, plus XP for every Mark above 1, plus the Mark XP of fitted modules. It goes up as you build and upgrade, and down if you demolish. The starter kit puts you at level 2.

Base level adds build-queue slots and raises the Mineral cost of re-typing tiles. The Bridge level, not the base level, is what unlocks buildings and tiles.

Repairing buildings

Damaged buildings are repaired from the Base View. Repairs need a Repair Bay, are paid up front and run on their own timer, outside the build queue.
